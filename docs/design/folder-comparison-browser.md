# 文件夹双栏浏览与排序

本次选择左右对齐目录作为默认界面，保留平面列表以便跨目录排序。实现位于 `zhangjy/folder`，只涉及文件夹比较；压缩包及其他并行工作区不在本次改动范围。

## 布局与交互

- 两边同一路径共用一个逻辑行。实际使用一张 AppKit `NSTableView` 承载左右名称、大小、可选修改时间及中间状态列，天然共用纵向滚动与选区，不进行两张表的滚动补偿。
- 默认目录模式，子目录折叠。任意一侧的箭头都展开同一对目录；仅一侧存在的大目录也只占一行。缺失侧有占位，不通过移动文件去填空。
- 双击目录进入该范围；上一级和全部目录返回父级／根。双击可配对的普通文件沿用文件比较流程。方向键支持展开、折叠与父子导航，⌘↓ 打开当前项。
- 平面列表显示相对路径，支持在当前子树内跨目录排序。切换模式不会扩大范围。
- 状态筛选包括全部、需关注、内容改动、仅左侧、仅右侧、问题和待校验。默认需关注；问题和待校验不会被隐藏为相同。
- 路径搜索限定当前范围。命中项保留祖先，搜索期间临时展开必要路径，清空查询恢复原展开状态。自动展开的箭头禁用，避免搜索污染用户保存的展开状态。
- 目录行显示克制的数量摘要，悬停可读完整分类；底部显示所选相对路径，多选则显示数量。

## 成对排序

| 表头 | 首次选择顺序 | 含义 |
| --- | --- | --- |
| 名称／相对路径 | 自然升序 | `file2` 位于 `file10` 前 |
| 状态 | 问题优先 | 类型冲突、读取问题、改动、仅左、仅右、待校验、相同 |
| 左／右大小 | 最大在前 | 使用该侧原始字节数，不比较格式化文本 |
| 左／右修改时间 | 最新在前 | 使用扫描快照，不为排序重新读取磁盘 |

再次点击反转顺序，表头显示方向。目录模式只排序兄弟节点且目录优先；列表模式全局排序当前范围。缺失元数据在升降序中均置后，0 字节是有效值。目录大小显示 `—`，不把目录自身占用冒充后代总大小。

左右行以完整相对路径为身份，排序永远一起移动。可选修改时间由列菜单控制，宽度自动分配；本轮不开放独立列拖动、类型排序或多列组合排序。

## 统计与可信状态

文件、链接等终端项和空目录计数；非空父目录的继承状态不重复增加总数。目录自己的读取问题／类型冲突另行计入，保留后代已知状态。统计对应当前子树，搜索、状态筛选与折叠不改变这个统计范围。

无法枚举的祖先会使另一侧可见的后代处于未知状态。Core 将其标为 `unreadable` 并阻止复制，界面显示“状态未知”，不声称已经确认该侧缺失。单侧存在也不直接解释为历史上的新增或删除。

## 选择与复制

每侧标题的“更换…”通过原生目录选择面板独立换源，取消和同路径选择保持原状态。会话观察层同步更新标题与路径；新根立即取消旧扫描、清空旧选择及范围，保留搜索、过滤、排序、忽略规则和展示偏好。复制核验、确认与执行期间禁止换源，执行入口只接受当前仍有效的预览计划。

排序、语言／主题切换和显示列切换保留路径选区。筛选、折叠或切换展示模式后，选择与可见路径取交集；隐藏选项退出复制范围且不会自动恢复。原生表保存首个可见路径及行内滚动偏移，数据更新后尽量恢复原位置。

选择目录仅用于浏览，不递归选择或复制其后代。普通文件复制保留现有流程：完整内容核验 → 方向与新增／覆盖预览 → 执行前重新核对。新 UI 的刷新、过滤、排序、展开本身均不写原文件。

刷新建立清单期间保留并标注上次快照；若取消或失败，仍可只读筛选、排序和浏览它，持续提示重新比较。旧快照不能参与复制；仅本轮完整比较结果拥有复制资格。

## 实现边界与性能

`FolderBrowser.project` 为 Foundation 层的纯展示投影，建立路径与父子索引、汇总分类、筛选并输出当前可见行。后台计算支持取消；模型使用 generation 防止旧任务覆盖新搜索或新扫描。原生表复用已创建的行，不在每行重新遍历整个目录。语言／主题更新同时刷新少量离屏缓存行，避免放大窗口后出现旧文案或低对比度文字；不会为刷新样式创建全部条目视图。

树模式只对可见的兄弟节点做自然排序，隐藏子树不展开成视图；平面模式需要全局排序。索引目前随投影重建，未实现增量索引。扫描期间若请求按状态排序，暂按名称保持稳定，核验停止后再应用状态排序。

实测生成文件样本中，1 万文件／侧的 10100 条清单投影约 0.025 秒（折叠树）／0.073 秒（平面）；10 万文件／侧的 101000 条清单约 0.612／1.443 秒。这只代表本机的后台投影耗时，不代表完整扫描、内存上限或十万行原生滚动验收。

## 代码与验证入口

- `Sources/CrossDiffCore/FolderBrowser.swift`：投影、统计、排序与搜索上下文。
- `Sources/CrossDiffCore/FolderComparison.swift`：现有内容比较、快照、未知后代与复制资格。
- `Sources/CrossDiff/FolderComparisonModel.swift`：会话内范围、展开、查询、选区及后台发布。
- `Sources/CrossDiff/NativeFolderComparisonTable.swift`：原生双栏、行复用、滚动、快捷键与表头。
- `Sources/CrossDiff/FolderComparisonView.swift`：工具栏、路径范围、复制预览及状态。

运行 `bash scripts/tests/check-folder-browser.sh` 验证纯投影与真实临时目录，添加 `--large` 使用十万文件样本。运行 `bash scripts/check.sh` 和 `bash scripts/tests/check-folder-performance.sh` 保持原比较／复制回归。`bash scripts/tests/check-folder-workflow.sh` 验证完整原生窗口交互，并输出中英文、浅深色、1220／860 宽度截图；`--build-only` 不代表原生验收通过。所有产物保存在项目内。
