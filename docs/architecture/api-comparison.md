# API 对比 · 首版实现范围

2026-10-02，CrossDiff 0.10.0 源码预览；实现前基线 `2ad8be9`。本设计记录用户批准的 API 对比插件范围。尚未发布，公开下载仍为 0.8.0。

## 用户要比较什么

左右各是一份 **HTTP 调用记录**：可同时含请求与响应，也可只有请求或响应。界面名称为 **API 对比 / API Compare**，说明为 **HTTP 请求与响应的结构化差异**。普通日志继续使用文本比较，不新增“日志”入口。PCAP、实时抓包、OpenAPI 契约、接口调用与压测不在首版范围。

从“新建…”选择 API 对比，分别粘贴内容或选择本地文件。支持 HTTP 文本、常见浏览器复制的 cURL 文本、HAR 1.2；HAR 有多条记录时，左右独立选定记录，不自动猜配对。JSON/XML/TXT 等普通文本文件仍默认走现有文本比较。

## 比较语义

- 请求：方法、URL、查询参数、HTTP 版本、请求头与 body；响应：状态码、HTTP 版本、响应头与 body。
- 头名称不区分大小写；不同头名称的排列不构成变化。同名头与同名查询参数保留重复项及其顺序，不能压成字典丢失值。
- JSON body 按 RFC 6901 路径展示字段，区分类型、缺失和 `null`，数组顺序有意义。数值词法内容无损保留，避免 Double 舍入抹掉大整数或高精度小数差异。重复键不静默覆盖。
- 非 JSON body 显示文本差异；XML 不宣称语义解析。无法提取、未记录、不可解码或超限内容必须报错或显示“不完整/未知”，不能当作相同。空 body 与未记录 body 不等价。
- 忽略头名称与 JSON 路径是用户显式规则，默认空。路径规则排除所选节点及子树；被排除项仍可查看并计数，不从报告中无痕消失。

## 原生交互与隐私

保留 CrossDiff 双栏与统一配色，顶部轻量工具栏，下方对齐字段。提供请求/响应视图、仅差异、搜索、原文查看、重新读取和忽略规则。中文、英文、浅深色与最小窗口宽度均需验收。

结构化结果默认隐藏常见凭据字段的值，但照常比较真实值；开关称作“显示敏感值”，不保证自动找出 body/URL 内的一切秘密。原文需要显式显示。输入和选项随本机会话保留，可通过既有清除记录入口移除；这不是磁盘加密或敏感信息清洗。

导入只解析文字，绝不执行 cURL、shell、环境变量展开、联网请求或读取命令中的 `@file`。不支持的 cURL 语义明确拒绝或诊断。所有源文件保持只读。

## 插件与宿主分工

- 宿主 `APIImporter` 有界读取、解析和规范化输入；`APIJSON` 保留数字词法、限制层深与节点数。
- 插件 `org.crossdiff.api` 在现有受限 JavaScript 子进程中实际执行字段匹配、分类与忽略规则，产出双语摘要。
- 输入 `httpExchange`，视图 `apiExchange`，结果 `crossdiff.api-exchange/1`；仅两方比较。相同契约可用于第三方插件，不靠官方 ID 跳过验证。
- 宿主验证输出并渲染。后台解析/比较可取消；版本或输入变化后丢弃过时结果。会话保存 HAR 选择和显式规则，切换标签不丢失。
- Full 预装，Base 可安装独立 `.crossdiffplugin`。包、官方目录、校验和与发行流程沿用统一插件清单。需要支持新契约的 0.10.0 宿主。

输入上限：每侧 4 MiB UTF-8、500 条 HAR 记录、每个 body 1 MiB、cURL 词法单元 20,000、JSON 深度 64/节点 20,000、每次调用最多 5,000 字段。结果最多 5,000 行；超限不得显示完整一致。读文件使用已验证的普通文件描述符，不跟随最终路径符号链接。

## 验收

解析检查覆盖重复项、请求/响应、Unicode、cURL 引号/拒绝危险语法、HAR 选择、缺失 body、JSON 精度/类型/重复键/深度以及只读边界。真实受限进程检查覆盖字段算法、显式忽略、未知状态、契约验证与输出上限。原生检查覆盖创建、安装、HAR 选择、规则恢复、认证头显示、切换标签与语言、浅深色和 860 px 窗口。交付需构建应用、验证签名并检查 Base/Full 与独立包。

## 协议参考

- [RFC 9110 HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110.html)：消息、字段与重复字段顺序。
- [RFC 8259 JSON](https://www.rfc-editor.org/rfc/rfc8259.html)：JSON 类型、数字与对象成员。
- [RFC 6901 JSON Pointer](https://www.rfc-editor.org/rfc/rfc6901)：字段路径与转义。
- [curl 官方手册](https://curl.se/docs/manpage.html)：导入子集的选项语义；本插件不运行 curl。
- [HAR 1.2 规范](https://github.com/ahmadnassri/har-spec/blob/master/versions/1.2.md)：请求、响应与内容记录。
