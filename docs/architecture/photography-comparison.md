# 摄影对比插件：实现设计

状态：2026-10-04，当前摄影分支源码，官方 Photography 0.1.0。本文包括首次摄影分析增强，公开安装包以各自 Release 说明为准；运行验证见 [0.13.1 验收记录](../validation/photography-enhancements-0.13.1.md)。

## 用户确认的目标

- 只读比较与学习，不提供修图、调色、镜头校正或照片导出编辑。
- 同时支持不同作品的风格比较与同一场景的版本观察，优先做好自己的照片与参考作品之间的影调／配色比较。
- 默认是双图、直方图和少量差异说明；专业图表按需展开。维持原生 Mac、浅深色、中英文与简洁界面。
- 左右独立框选，提供联动；首版支持保存并反复切换多组区域。
- 同时提供影调分布与实际记录的处理曲线；缺失不推测。
- 专业算法由 Apple 官方接口或成熟专业开源库提供，禁止自行从像素矩阵重写色彩转换、RAW 显影或专业影调算法。

此方向取代早期允许调色预览的提案。基础图片比较的缩放、旋转与四角变换不受影响；摄影视图使用独立分析管线。

## 用户工作流

完整版预装摄影插件；同版本宿主的基础版可以通过普通插件流程安装独立包。用户在“新建… → 摄影”准备两张照片；普通图片自动打开继续进入基础图片比较，不擅自改为摄影分析。

主区域呈现两张照片，以一致的中性底色衬托图像。照片默认显示原图，两侧可同步切换红／绿／蓝通道灰度预览；照片预览与图表通道独立。统一分析区默认以分开布局显示 Lab 感知明度 L*，点击“叠加”按钮才切换为叠加；也可选择 RGB 三图总览、单个通道或右减左差值布局。左右使用相同刻度和有效像素占比，A／左侧是蓝色实线，B／右侧是橙色虚线；差值图用蓝色表示 A 占比更高、橙色表示 B 占比更高，单位为百分点。悬停联动两侧同一分箱。摘要显示 L* 中位数、P90−P10 跨度和低／高明度占比。展开“专业图表”后继续查看 HSL、处理曲线和拍摄／分析信息。拍摄参数按字段左右对照，缺失记录明确显示。

框选以显示方向校正后的源图归一化坐标表示，原点在左上；显示缩略图、窗口尺寸和留白不改变选区含义。拖动中显示框，松开后统计。默认左右独立；联动只复制后续框选的归一化坐标和比例，不识别或配准相同物体。最多保存 32 组命名的左右选区，每个名称最多 256 UTF-8 字节；可以切换、删除或回到全图。区域、显式选择的 XMP 路径、预览通道、直方图通道和布局随本机会话恢复；旧会话缺少新增字段时采用原图、感知明度和分开布局；已保存的布局按原选择恢复。

在图表上拖选分箱范围，只在两侧当前 ROI 内高亮匹配的预览像素；清除高亮恢复显示。高亮是临时查看状态，不改变 ROI、分析统计、文件或持久化图像。通道灰度和高亮在后台生成，过期结果不能覆盖最新选择。点击查看预览可以放大，但放大比例相对于预览像素，不宣称原图 100% 细节。所有操作保持源文件字节不变。

## 分析管线与专业依赖

| 层次 | 实现与语义 |
| --- | --- |
| 图像读取／方向／元数据 | Apple ImageIO 与 Core Image；普通图片尊重颜色配置和格式颜色标签，EXIF 仅展示存在的拍摄记录 |
| RAW | Apple `CIRAWFilter`，关闭草稿、完整默认显影；不能解码则失败，不把内嵌预览当作完整 RAW |
| 颜色管理 | Core Image 浮点工作数据，统计输出统一为 sRGB SDR 0–1；范围外值截到端点，明确不据此判定 RAW 过曝 |
| 区域与有界重采样 | Core Image 裁切与 `CILanczosScaleTransform`；分析来自颜色管理后的源选区，不来自显示缩略图 |
| Lab、HSL 与直方图 | OpenCV **4.12.0** 的 `cvtColor(COLOR_RGB2Lab)`／`cvtColor(COLOR_RGB2HLS)` 与 `calcHist`；Lab L* 为 0–100 感知明度，HLS 中 L 为独立保留的 HSL 明度，均不是物理亮度或曝光值 |
| 处理曲线 | ImageIO 解析实际 Adobe CRS XMP 控制点；同时支持内嵌记录和用户显式选择的旁路 XMP，选定旁路时以其记录为准 |
| 图表与说明 | 宿主绘制库输出的分布；受限 JavaScript 插件计算占比差值和双语说明，不实现底层摄影算法 |

摄影使用 OpenCV `core`／`imgproc` 静态模块，由 Base／Full 宿主共同提供；0.13.0 图片智能对齐另增加 `features2d`／`calib3d`／`flann`。源码和必要 CMake 工具以固定摘要下载，依赖、工具和产物均在项目 `.build/photo-deps/` 内；无全局安装。固定来源、版权和许可见 [ThirdParty/OpenCV](../../ThirdParty/OpenCV/)。不把自行编写的像素循环包装成“采用专业库”。

### 统计定义与边界

- RGB、Lab L*、HSL L、HSL S 各 256 个分箱；H 为 360 个分箱。Lab L* 的横轴为 0–100；RGB／HSL L／S 显示为百分比，H 为角度。
- 完全透明和非有限样本排除，其余有效像素等权；部分透明像素颜色在解预乘后参与统计。
- HSL S < 0.02 为近中性色，不进入色相分布。所有分布都除以有效像素总数，因此 H 分布和为 `1 - neutralFraction`，其余分布和为 1。
- 默认摘要来自 Lab L* 分布：P50 中位数、P90−P10 跨度以及低／高明度占比，分位数按分箱估计。旧插件的 HSL 分布说明继续可用。这些是分布摘要，不是曝光计、动态范围测量或客观作品评分。
- 每张文件最多 256 MiB、6400 万像素。显示预览最长边 2048，高亮基于此预览生成；源选区统计独立进行，最长边超过 4096 时进行有界采样，界面显示状态与分析尺寸。两种采样在细小纹理或边缘处可能导致高亮覆盖与统计占比略有差异；高亮不反馈改变统计。多帧只处理首帧。
- RAW 支持取决于 macOS、具体机型和编码模式；后缀被接收不等于保证解码。Apple 默认显影既不是传感器原始数值，也不是原作者调色后的结果。没有真实样片覆盖的机型不能宣称已验证。

### 两类曲线与元数据

默认“影调分布”是当前图像的 Lab 感知明度分布；专业色彩分析继续单独显示 HSL 明度。两者都不恢复编辑器曲线。“处理曲线”读取 Adobe Camera Raw Settings 命名空间中的 `ToneCurvePV2012`／RGB 通道记录，缺失时回退到实际存在的 legacy `ToneCurve` 系列字段。控制点和来源、ProcessVersion 一并显示；没有记录时明确写“未记录处理曲线”。连线只是示意，不复现原软件的插值与显影。

旁路 XMP 必须由用户显式选择，不自动扫描相邻文件，上限 8 MiB，拒绝文档类型／实体声明和非法点序列。快门、光圈、ISO、焦距、镜头等仅来自元数据。照片偏蓝不能推导确定的 Kelvin 色温；直方图无法确定曝光调整值、快门速度或原作者的 HSL 滑块。

## 插件与宿主职责

新增实验契约 `inputKind: photoAnalysis`、`resultView: photography`、`schema: crossdiff.photography/1`，目前仅两方 `pairwise`。它按能力和 schema 路由，不以官方插件 ID 决定分析执行。第三方可使用自己的 ID 和相同视图／统计输入；当前不能动态装入未实现的图表或原生依赖。

宿主保留像素、绝对路径、拍摄信息和 XMP。插件收到有限长度的归一化分布、中性色比例、采样说明和文件名；返回最多 8 条双语 `findings`，每种语言每条最多 2048 UTF-8 字节。宿主验证输入、schema、runID 与结果范围，插件说明在分析信息中显示，默认摘要由宿主根据 Lab L* 分布计算。协议详见[中文插件规范](../plugins/development.md#crossdiffphotography1)与[英文规范](../plugins/development.en.md#crossdiffphotography1)。

解码和统计在后台进行，来源重载、区域改变、标签关闭／切换及插件管理变化都可能取消旧任务。结果发布前校验 generation，避免旧选区覆盖新选区。统计、预览和临时高亮不写入源图或持久化图像数据；持久化只保留来源、插件、区域、显式 XMP 选择及显示通道／布局等会话状态，不保存临时悬停或高亮范围。

## 验证入口与未实现范围

- `check-photo-engine.sh`：真实 OpenCV 色块、灰阶、端点、透明度、ICC、16 位输入、方向、ROI 与有界采样；无效 RAW 明确失败。
- `check-photo-metadata.sh`：内嵌／旁路 XMP、命名空间、缺失／非法曲线与源文件保持。
- `check-photography-plugin.sh`：实际受限子进程、输入／输出契约、说明语义、区域状态与旧会话兼容。
- `check-photo-workflow.sh`：真实原生窗口、独立／联动／命名区域、过期结果、会话、XMP 和基础版本地插件安装；浅深色、中英文及窄窗口。

波形、RGB Parade、矢量示波图、噪声／锐度指标、物理亮度、HDR 专业分析、镜头／透视诊断和报告导出均为后续候选。每个专业指标须先核实现成实现、值域和可解释性，再进入产品；不以未经验证的自创算法填充。只读定位继续排除修图和调色功能。
