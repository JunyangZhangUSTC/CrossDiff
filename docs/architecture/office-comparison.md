# Office 内容比较 · M1

CrossDiff 0.12.0 源码预览。已确认范围与选择记录于 [ADR 0003](../adr/0003-office-content-comparison.md)，外部依据见 [调研](../research/office-comparison.md)。

## 输入与可信边界

一个 Office 0.1.0 官方包以 `officeDocument → officeDocuments → crossdiff.office/1` 复用受限 JavaScript 进程。宿主处理 DOCX/XLSX/PPTX 文件与原生显示。现代格式必须同类配对；旧 DOC/XLS/PPT 提示转换。

`OfficeImporter.load(URL)` 持有只读文件描述符并核对变化，复用 ZIP 中央目录、本地头、CRC 与 system libarchive 流式解码；不解压到磁盘。OOXML 主部件、工作表、幻灯片按关系读取，不按文件名猜顺序。XML 禁 DTD/实体、外部解析，控制节点、深度、文字与单元格预算；外部关系仅提示，不加载。MCE AlternateContent 仅读取唯一兼容 Fallback 并给出说明，缺少 Fallback 明确拒绝；不混合 Choice 与 Fallback 的文字。

文件上限 128 MiB、解码 256 MiB、单 XML 16 MiB、保留 XML 64 MiB。请求 16 MiB、结果 8 MiB；每部分至多 10,000 行，另有全局单元格、节数和文本预算。上限是可靠退出条件，不是大文件性能保证。

## 三种内容模型

- Word：当前可见段落、表格行及读取到的页眉页脚、脚注等部分。已有删除修订不作为当前正文；比较修订历史不是本版目标。
- Excel：稀疏单元格保留列号、原值、类型、公式、保存结果和格式记录。共享字符串先解析。共享公式保留声明与组信息，不自写公式重算器；日期保留来源序列及格式说明。隐藏、合并与格式范围通过诊断提示。
- PowerPoint：按播放顺序读取幻灯片文字、表格及备注。对应由用户选择的两个部分确定；内容相同不证明图片、主题、动画、母版或视觉效果相同。

快照是只读内容子集。文件格式、字体、排版、图片、图表、嵌入对象等不完整参与一致判定；UI 常驻“内容比较”和“当前部分”计数，范围入口进一步说明遗漏。

## 匹配与呈现

插件先按类型、值与公式的精确内容匹配，不受原行号限制；保留 Unicode 和数值字符串精度。相同行的重复次数一对一消耗，并说明歧义。可选关键列对剩余记录做唯一键匹配；重复与空键不强行绑定。无键的剩余记录按位置对照，并标明不是身份判定。

相同、修改、单侧内容和相对顺序重排是分开的维度；插入引起的整体行号偏移不会全部报移动。宿主验证一对一来源覆盖、单元格状态和依据，UI 根据源快照显示文本，插件输出不可替换文档内容。

Excel 使用双侧网格，保留原行号，按单元格着色；多列以列组加横向滚动查看。Word/PPT 内容块提供 UTF-16 字符高亮，短预览有上限，详情保留全文。搜索、仅差异、关键列、左右选择及状态计数组成统一控件。范围有歧义或匹配部分完成时明确标出。

## 生命周期与原件

`OfficeComparisonModel` 在后台读取和比较，取消后等待前一任务收尾，发布前核对代次。关键列和部分选择只比较已有快照，手动重新读取才获取外部改动；会话只保存文件来源和选项，不保存解析内容。左右选择独立，左侧默认按同名、再按位置建议右侧。

原文件预览使用按需 `QLPreviewView`，只读取当前磁盘文件。可用格式和排版由 macOS 决定，不声称差异可精确映射到原文件某页。预览失败不改变结构比较。所有比较均只读，不提供合并保存，不运行公式、宏或外链。
