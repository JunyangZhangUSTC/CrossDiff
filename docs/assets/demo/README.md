# 演示风景 / Demo landscape

`alpine-lake.png` 是 CrossDiff 为功能演示创建的原创程序插画，不是相机实拍，不代表真实地点。它由 `scripts/tests/ReadmeMediaFixtures.swift` 的 `landscape()` 使用固定随机种子生成；山脉、天空、水面和树木用于展示真实的图像局部匹配与色调分析。

截图流程在项目内生成裁剪、暖色调变体和视频帧，原图保持不变。执行 `bash scripts/render-readme.sh` 可重现输入素材及应用截图。

This original procedural illustration is generated by `ReadmeMediaFixtures.landscape()` with a fixed seed. It is not a photograph or a real location. Cropped, graded and animated derivatives demonstrate actual CrossDiff analysis without using personal or third-party media. The artwork is distributed under this repository's AGPL-3.0 license.
