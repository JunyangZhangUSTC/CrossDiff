## 简体中文

**CrossDiff 0.4.0 · macOS 开发预览版**

原生、免费开源的本地对比工具，支持文本与代码文件、文件夹和图片。无需账号，不上传文件；完整支持简体中文与 English。

### 这个版本可以做什么

- 查看字符与整行差异、对应行对齐、同步滚动；左右编辑、逐块合并、独立撤销，手动保存。
- 在右侧开启“显示删除”，用红色删除线审阅移除内容；修订标记不会进入保存的原文。
- 使用原生 Mac 菜单与快捷键，查找、替换、清空两侧，并在本机恢复临时比较。
- 比较目录、筛选差异，复制选中文件前预览新增与覆盖项。
- 并排、叠加或拖动分界线比较图片，查看差异图。
- 使用浅深色外观、双语界面与独立设置窗口。

### 下载与首次打开

需要 **macOS 14 或更高版本、Apple 芯片（arm64）**。Intel 应用和通用二进制不包含在本次发布中。

| 附件 | 用途 |
| --- | --- |
| `CrossDiff-0.4.0-macOS-arm64.zip` | 解压后获得 `CrossDiff.app` |
| `CrossDiff-0.4.0-source.tar.gz` | 与应用对应的完整源码 |
| `BUILD-INFO.txt` | 版本、源码提交、架构与签名信息 |
| `SHA256SUMS` | 以上三个文件的 SHA-256 校验和 |

下载附件至同一目录后，可运行 `shasum -a 256 -c SHA256SUMS` 核对完整性。

**本版本仅有 ad-hoc 签名，没有 Apple Developer ID 签名，也未公证。** 核对下载来源后，解压并尝试打开一次；如 macOS 阻止打开，前往 **系统设置 → 隐私与安全性 → 仍要打开**，按提示确认。无需全局关闭 Gatekeeper。完整说明和源码构建方式见 [中文 README](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.4.0/README.md)。

### 已知边界

- 仍是开发预览；PDF、Word、表格与三方合并尚未实现，文件夹暂不支持完整同步。
- 文本文件上限为 20 MB；图片使用最长边不超过 1600 像素的预览。
- 本机会话文件含明文内容与路径，不做加密；可在“会话”菜单清除记录。
- 发布自动化运行核心检查并编译原生完整工作流检查程序；原生窗口交互、显示效果及真实输入法仍需另行验收，不能仅凭 CI 编译判断通过。

## English

**CrossDiff 0.4.0 · macOS development preview**

A native, free and open-source app for local text, code, folder, and image comparisons. No accounts or uploads. Available in English and Simplified Chinese.

### What you can do

- Inspect character and line changes with aligned rows and synchronized scrolling; edit either side, merge individual blocks, undo independently, and save explicitly.
- Enable **Show Deletions** to review removed content as red strikethroughs on the right; review marks never enter saved source text.
- Use native Mac menus and shortcuts, find and replace, clear both sides, and restore temporary comparisons locally.
- Compare folders, filter differences, and preview additions or overwrites before copying selected files.
- Compare images side by side, with an overlay or draggable divider, and view a difference image.
- Choose light or dark appearance and switch languages in a separate settings window.

### Download and first launch

Requires **macOS 14+ and Apple silicon (arm64)**. This release does not include an Intel app or a universal binary.

| Asset | Purpose |
| --- | --- |
| `CrossDiff-0.4.0-macOS-arm64.zip` | Extract to get `CrossDiff.app` |
| `CrossDiff-0.4.0-source.tar.gz` | Exact corresponding source |
| `BUILD-INFO.txt` | Version, source commit, architecture, and signing information |
| `SHA256SUMS` | SHA-256 checksums for the three files above |

Download the assets into one directory and run `shasum -a 256 -c SHA256SUMS` to verify their integrity.

**This build is ad-hoc signed, without an Apple Developer ID signature or notarization.** Check the download source, extract the app, and try opening it once. If macOS blocks it, open **System Settings → Privacy & Security → Open Anyway** and follow the confirmation prompts. Do not disable Gatekeeper system-wide. See the [English README](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.4.0/README.en.md) for details and source-build instructions.

### Known limits

- This is a development preview. PDF, Word, spreadsheets, and three-way merging are not implemented; folders do not support full synchronization.
- Text files are limited to 20 MB. Image previews are limited to 1600 px on the longest edge.
- Local session files contain unencrypted text and paths; clear them through the Session menu.
- Release automation runs core checks and compiles the integrated native workflow checks. Real window interaction, appearance, and physical input-method behavior require separate verification; CI compilation alone does not establish a pass.
