# CrossDiff 0.8.0

**对比一切，从本地开始。无需注册，打开即用。**

这次预览版将此前的插件、图片变换、Hex、压缩包和新建流程一起带到 GitHub，并提供两种应用组合与独立插件下载。

| 下载 | 包含内容 |
| --- | --- |
| `CrossDiff-0.8.0-base-macOS-arm64.zip` | 文本／代码、文件夹、图片、Hex 与官方压缩包插件 |
| `CrossDiff-0.8.0-full-macOS-arm64.zip` | 基础版全部能力，加上已实现的官方 PDF 插件 |
| `CrossDiff-Plugin-*.crossdiffplugin` | 可独立安装的官方插件包 |
| `CrossDiff-Example-JSON-*.crossdiffplugin` | 面向开发者的 JSON 键值比较示例插件 |

- “新建…”先选类型，再准备左右内容；临时文本、文件和插件比较共用入口。
- 图片支持缩放、旋转、四角调整、比例锁与翻转；Hex 保留真实偏移，压缩包与本地文件夹可以互比。
- 插件页的官方目录可以离线查看。点击“下载并安装”后，应用从此版本的 Release 下载，核对包字节、标识、版本和兼容性，再完成安装与启用。
- 比较仍在本机完成，不上传文档、无需账号、没有遥测。联网仅用于用户主动请求的插件下载；第三方原生插件保留独立的完全信任授权。
- 中英文 README、宣传图和真实应用截图已更新。源码、构建信息、插件目录与 `SHA256SUMS` 随版本一起提供。

需要 macOS 14+；此发行面向 Apple 芯片。应用使用 ad-hoc 签名，尚未使用 Developer ID 签名或 Apple 公证；[首次打开说明](https://github.com/JunyangZhangUSTC/CrossDiff#首次在-macos-上打开)。解压后使用其中的 `CrossDiff.app`，无需安装开发工具。

“完整版”包含当前已经发布的官方插件。Office、摄影／RAW、音视频、数据库、模型对比和三方工作台仍在规划中；PDF 不含 OCR，远程来源尚未实现。详见[使用指南](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.8.0/docs/usage.md)与[验证记录](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.8.0/docs/validation/validation-0.8.0.md)。

**Compare everything. Start locally. No account required.**

This preview brings the plugin framework, image transforms, Hex, archive comparisons and the new comparison flow to GitHub, with two application editions and separate plugin downloads.

- **Base:** text/code, folders, images, Hex and the official Archive plugin.
- **Full:** everything in Base plus the released official PDF plugin. Planned professional plugins are not included.
- **Standalone plugins:** official `.crossdiffplugin` packages, plus a separately labelled JSON developer example.
- **Download & Install:** browse the bundled official catalog offline, then explicitly request a version-pinned GitHub Release download. The app verifies package bytes, identity, version, compatibility and restricted runtime before installation.
- Comparisons process your documents locally without uploads, registration or telemetry. Plugin downloading is a separate, user-initiated operation. Native third-party plugins retain explicit full-trust authorization.

Requires macOS 14+ on Apple silicon. Ad-hoc signed, without Developer ID signing or notarization; see the [first-launch instructions](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.8.0/README.en.md#first-launch-on-macos). Matching source, build information, `plugins.json` and `SHA256SUMS` accompany the downloads. Office, photography/RAW, audio/video, databases, model comparison, remote sources and three-way workflows remain planned; PDF OCR is not included.
