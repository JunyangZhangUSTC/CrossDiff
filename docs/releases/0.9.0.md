摄影对比，让你看见照片之间的影调与配色差异。无需账号、无需上传照片，分析在 Mac 本机完成。

- **Photography 0.1.0：** 大幅双图、RGB 与 HSL 明度直方图，默认只显示少量统计说明；展开后查看 HSL 色彩分布、拍摄信息和文件记录的处理曲线。

- **曲线有据可查：** 读取内嵌或明确选择的 XMP 控制点，缺失不推测；不把明度分布冒充曝光设置，不从照片还原原作者的调色滑块。

Draft release notes for the unpublished 0.9.0 source preview. The public download remains 0.8.0.

**🌟 Download guide: choose Base for everyday comparisons, or Full to try PDF and Photography immediately. Once 0.9.0 is published, use `CrossDiff-0.9.0-base-macOS-arm64.zip` or `CrossDiff-0.9.0-full-macOS-arm64.zip`.**

Photography Comparison reveals differences in tone and color without accounts or uploads. Processing stays on your Mac.

- **Photography 0.1.0:** paired photos, RGB/HSL lightness histograms and concise statistics. Expand the analysis panel for HSL color, capture metadata and recorded processing curves.
- **Compare regions:** independent or linked rectangular selections, with up to 32 named pairs restored locally with the session.
- **Professional components:** Apple ImageIO, Core Image and CIRAWFilter handle decoding/RAW/color management; OpenCV 4.12.0 supplies HSL conversion and histograms. All comparisons remain read-only.
- **Recorded curves only:** read actual embedded or selected XMP points; missing records are never inferred. Distributions do not recover exposure settings or the creator’s editing sliders.

Full adds PDF and Photography to Base. A matching 0.9.0 Base host can install `CrossDiff-Plugin-Photography-0.1.0.crossdiffplugin`; the 0.8.0 host does not support photography inputs.

Each photo is limited to 256 MiB/64 megapixels. Previews have a 2048 px longest edge; ROI statistics explicitly resample above 4096 px. Statistics use sRGB SDR 0–1, and HSL L is not physical luminance. RAW support depends on macOS, camera and encoding; unsupported files fail without embedded-preview substitution. HDR analysis, waveforms, noise/sharpness scores and photo editing are not included. See the [usage guide](../usage.md#photography).

Requires macOS 14+; releases target Apple silicon. Ad-hoc signed, without Developer ID signing or notarization. The existing release workflow prepares matching source, notices, build information, plugin catalog and checksums. Until publication, use local plugin packages rather than the unreleased catalog download URLs.
