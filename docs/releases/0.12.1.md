- **更快看到文件夹差异：** 先显示路径、类型与大小差异，再以有限并发核验内容；单侧或大小不同的文件无需读取全部内容。新增进度、取消、忽略规则与标签内结果保留，切回标签不再重复扫描。
- **更直接地管理插件：** 默认显示“已安装”，卸载按钮直接放在卡片上；“发现插件”集中展示可安装功能。本地安装插件可卸载，预装插件可移除并离线恢复，保留原文件和比较会话。移除预装插件不会改写签名包或减少应用体积。
- **修复文本换行显示：** 长段落插入换行后，对齐留白不再出现白绿拼块，保留正常的编辑、选区和撤销行为。
- **更新关于窗口：** “对比一切，把每一处变化看清。”新增可点击的 GitHub 链接，中英文与浅深色界面保持一致。

Uninstall local plugins or remove and restore bundled plugins offline, while retaining files and sessions. Removing a bundled plugin does not modify the signed app or reduce its size.
- **Fixed wrapped text backgrounds:** inserting newlines in long paragraphs no longer leaves inconsistent blocks in alignment gaps. Editing, selection and undo are preserved.
- **Refreshed About window:** “Compare everything. See every change.” A clickable GitHub link is available in both languages and themes.
