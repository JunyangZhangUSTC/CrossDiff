# CrossDiff 0.7.1

**先选比较类型，再准备左右内容**

- 主工具栏“新建…”（⌘N）打开类型选择页，再进入左右内容选择。文本每侧都可使用临时文字或文件。
- 内置比较与已启用的插件集中展示；“更多对比项”打开插件管理。“比较”菜单可直接进入对应类型的输入页。
- “文件 → 打开…”（⌘O）保留自动识别和多项明确配对，Finder 打开与拖入工作流继续可用。

需要 macOS 14+。仅 ad-hoc 签名，未做 Developer ID 签名与公证。使用方法见[使用指南](../usage.md)。

---

**Choose what to compare, then prepare both sides**

- **New…** (⌘N) opens a comparison-type chooser followed by left and right inputs. Either text input can use temporary text or a file.
- Built-in comparisons and enabled plugins share one chooser. **More Comparisons** opens plugin management, while the Compare menu goes directly to a type’s input page.
- **File → Open…** (⌘O) retains automatic detection and explicit multi-item pairing. Finder opening and drag-in workflows remain available.

Requires macOS 14+. Ad-hoc signed, without Developer ID signing or notarization. See the [user guide](../usage.md).
