# CrossDiff 0.11.0

发布说明草稿：源码开发预览，尚未发布。当前公开下载仍为 0.8.0。

**🌟 下载指南：日常比较选 Base；想直接使用音频、PDF、摄影和 API 对比，选 Full。发布后下载 `CrossDiff-0.11.0-base-macOS-arm64.zip` 或 `CrossDiff-0.11.0-full-macOS-arm64.zip`。**

本版同时带来 **API 与摄影对比**：HTTP／cURL／HAR 的头、参数和 JSON 字段差异，以及照片的 RGB／HSL 统计、区域对照与拍摄信息。三种专业插件均预装于 Full，也提供独立安装包。

音频对比，让两段声音的形状、频谱与共同片段可以直接查看。无需账号、无需上传，分析与试听都在 Mac 本机完成。

- **专业图表：** 独立声道波形、STFT 时频图、平均频谱；两侧共用分析参数和标尺，可展开设置 FFT 窗长、步长、线性／对数频率轴与 dB 显示范围。
- **局部比较：** 拖动选择、移动或调整范围，放大选区、保存多组区域对，支持撤销、重做和本机会话恢复。
- **只读试听：** A/B 切换、选区循环、B 侧独立速度／音高调整，不覆盖原音频。参数随区域组保存。
- **自动对应：** 固定版本的 Olaf 原生指纹引擎寻找同源录音的截取、重排和重复片段，支持多个候选；边界为指纹覆盖范围，需试听确认。
- **本地插件：** Full 预装 Audio 0.1.0；同版本 Base 可以安装独立包，不需要用户安装 Python、Java 或 FFmpeg。

Draft release notes for the unpublished 0.11.0 source preview. The public download remains 0.8.0.

**🌟 Download guide: choose Base for everyday comparisons, or Full for Audio, PDF, Photography and API Compare out of the box. Once published, download `CrossDiff-0.11.0-base-macOS-arm64.zip` or `CrossDiff-0.11.0-full-macOS-arm64.zip`.**

This preview also brings **API and Photography comparison**: structured HTTP/cURL/HAR headers, parameters and JSON differences, plus photo RGB/HSL statistics, region pairs and capture metadata. All three plugins ship with Full and as standalone packages.

- Inspect per-channel waveforms, STFT spectrograms and average spectra with shared parameters and scales.
- Select, move and resize regions, zoom in and save named region pairs with undo/redo and local session restoration.
- Audition A/B or loop a region; adjust B's rate and pitch independently without modifying source files.
- Find fixed-speed, same-source excerpts, reordered edits and repeated candidates through a pinned native Olaf engine. Audition candidates to verify them; boundaries reflect fingerprint coverage.
- Full bundles Audio 0.1.0. A matching Base host can install `CrossDiff-Plugin-Audio-0.1.0.crossdiffplugin`. No Python, Java or FFmpeg installation is needed.

Automatic independent tempo/pitch recognition, exact edit boundaries and continuous speed changes remain research work. Unmatched does not mean deleted. Inputs are limited to 2 GiB, two hours and eight channels per side; audition currently supports mono/stereo. Spectra analyze up to the first 30 seconds of a selection, with explicit reduced ranges for dense settings. Codec support is probed by macOS. [Usage](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.11.0/docs/usage.md#audio)

Requires macOS 14+; release target is Apple silicon. Ad-hoc signed, without Developer ID signing or notarization. Use local builds and packages until publication makes catalog downloads available.
