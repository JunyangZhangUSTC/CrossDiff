# CrossDiff 0.12.0

源码开发预览，尚未发布。公开下载状态以 README 为准。

**🌟 下载指南：日常使用选 Base；需要办公文档、PDF、摄影、API 和音频对比，直接选 Full。发布后下载 `CrossDiff-0.12.0-full-macOS-arm64.zip` 即可使用办公插件。**

新增 Office 0.1.0：DOCX 段落与表格、XLSX 跨行匹配与多关键列、PPTX 幻灯片内容。左右原行号、字符／单元格高亮、公式与保存的结果、搜索和只读原件预览，统一浅深色与中英文界面。Full 预装；同版 Base 可安装 `CrossDiff-Plugin-Office-0.1.0.crossdiffplugin`。

首版支持现代 DOCX/XLSX/PPTX 内容子集；旧格式需转换，排版、图表与图片等不作完整视觉比较。结果针对所选部分，重复键与空键提示不确定，不执行公式或宏、不修改原件。

**English:** Choose Base for everyday comparisons, or Full for Office, PDF, Photography, API and Audio out of the box. Once published, `CrossDiff-0.12.0-full-macOS-arm64.zip` includes Office 0.1.0. A matching Base host can install the standalone Office package.

Compare DOCX paragraphs/tables, XLSX rows across positions or by multiple key columns, and PPTX slide content. Native read-only views retain source coordinates, show character/cell differences and formulas with saved results, and provide search plus optional original previews. Modern formats only; this is a bounded content comparison, not complete visual identity or an Office editor. Legacy files require conversion; duplicate/empty keys remain uncertain.

Requires macOS 14+, Apple silicon release target. Ad-hoc signed; no Developer ID or notarization. Catalog downloads become available only after publication.
