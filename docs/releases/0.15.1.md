0.15.1 正式版将 Git 纳入基础比较能力，让历史版本和未提交修改都能在同一个原生工作台里看清，同时改善多标签浏览和摄影分析。

- **Git，从提交到工作区：** 打开本地仓库、裸仓库或 worktree，也可主动获取 HTTPS／SSH 远程仓库。比较分支、标签或提交，或者直接选择“全部未提交”“已暂存”“未暂存”；两侧来源可自由组合，无需先 commit 或 stash。
- **一棵树，双栏看细节：** 目录树支持仅差异／全部文件、路径搜索和折叠；选中文件后查看字符差异、行对齐、同步滚动与查找。支持重命名识别、共同祖先比较和有明确范围的二进制预览。只读查看，不切换分支，不修改原文件或暂存区。
- **大型仓库可继续比较：** 取消仓库扫描的单文件大小、总字节数、文件数量和总时长固定限制，采用流式目录读取、分块摘要及分批核验；后台比较显示进度并可取消。文件详情仍保留每侧 2 MiB 预览上限，远程下载另有资源边界。
- **多标签，当前比较始终找得到：** 标签超出窗口时，悬停显示可拖动的横向滚动条，支持触控板与普通滚轮。新建、切换、关闭标签及调整窗口后自动显示当前标签，同时保留手动浏览位置；修复图标及留白处首次点击不响应的问题。
- **摄影，专业图表直接展开：** 默认显示影调、色彩 · HSL、处理曲线和拍摄与分析信息，仍可手动收起。修复高饱和颜色在浮点边界漏计，导致“histogram normalization”报错及近中性色误判的问题，保留严格的数据校验。
- **系统 Git 兼容性：** 修复暂存区元数据读取依赖较新 Git 输出格式的问题，让较旧的系统 Git 也能读取暂存内容与工作区。
- **新建入口更顺手：** 文本、文件夹、图片、Git、二进制、压缩包优先排列，其余已启用插件继续显示。

Full 包含压缩包、Git、PDF、摄影、API、音频、办公和视频八个官方插件。只需要基础比较？下载 [Base 基础版](https://github.com/JunyangZhangUSTC/CrossDiff/releases/download/v0.15.1/CrossDiff-0.15.1-base-macOS-arm64.zip)，已包含 Git 与压缩包，其他插件可从应用内或本版附件按需安装。

比较继续在本机运行，无需注册、不上传比较内容。只有你主动下载插件或获取远程 Git 仓库时联网。Git 需要系统 Git（Apple Command Line Tools 提供）；HTTPS 支持公开仓库，SSH 使用已有密钥与已信任主机，私有 HTTPS 仓库可先用自己的 Git 工具克隆后本地打开。Git 比较不提供暂存、提交或冲突解决。[使用指南](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.15.1/docs/usage.md#git)

The 0.15.1 stable release brings Git into the core comparison workspace, covering history and uncommitted changes, with smoother tab browsing and more reliable photography analysis.

- **Git, from commits to your working tree:** open local repositories, bare repositories or worktrees, or explicitly fetch an HTTPS/SSH remote. Compare branches, tags or commits, or choose All Uncommitted, Staged or Unstaged. Select either source independently without committing or stashing first.
- **One tree, paired details:** browse changes only or all files, search paths and collapse folders. Select a file for character highlights, aligned rows, synchronized scrolling and Find. Rename detection, merge-base comparisons and labeled binary previews are available. Viewing is read-only: no checkout, file edits or index changes.
- **Keep comparing large repositories:** repository scans no longer impose fixed per-file, total-byte, file-count or elapsed-time caps. Streaming directory reads, chunked hashing and batch validation provide cancellable background progress. Detail previews still allow up to 2 MiB per side, with separate remote-download resource limits.
- **Keep the active tab in view:** overflowing tab bars show a draggable horizontal scroll bar on hover, with trackpad and mouse-wheel support. Creating, selecting or closing tabs and resizing the window reveal the active tab while ordinary updates preserve manual browsing. Icon gaps and padding now respond to the first click.
- **Professional photography charts, open by default:** Tone, Color · HSL, Recorded Curves, and Image & Analysis are directly available and can still be collapsed. Correct handling of floating-point endpoints prevents saturated pixels from being dropped, fixing histogram normalization errors and false near-neutral classifications without weakening validation.
- **System Git compatibility:** staged metadata reading no longer depends on newer Git output formatting, allowing older system Git installations to read the index and working tree.
- **A clearer New flow:** Text, Folders, Images, Git, Binary and Archives come first, followed by other enabled plugins.

Full includes all eight official plugins: Archive, Git, PDF, Photography, API, Audio, Office and Video. Only need the essentials? [Download Base](https://github.com/JunyangZhangUSTC/CrossDiff/releases/download/v0.15.1/CrossDiff-0.15.1-base-macOS-arm64.zip), with Git and Archive included, then add other plugins in the app or from this release's assets.

Comparisons run locally without sign-up or uploading content. Connections happen only when you initiate a plugin download or remote Git retrieval. Git requires system Git from Apple Command Line Tools. HTTPS supports public repositories; SSH uses existing keys and trusted hosts. Clone private HTTPS repositories with your own Git client, then open them locally. Git Compare does not stage, commit or resolve conflicts.
