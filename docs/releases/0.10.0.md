# CrossDiff 0.10.0

发布说明草稿：源码开发预览，尚未发布。当前公开下载仍为 0.8.0。

**🌟 下载指南：日常比较选 Base；想直接使用 PDF、摄影和 API 对比，选 Full。发布后下载 `CrossDiff-0.10.0-base-macOS-arm64.zip` 或 `CrossDiff-0.10.0-full-macOS-arm64.zip`。**

API 对比，把请求与响应里的变化拆开看清楚。无需账号、无需上传数据，所有解析与比较在 Mac 本机完成。

- **API Compare 0.1.0：** 粘贴 HTTP／cURL，或导入 HAR；逐项查看方法、地址、查询参数、头、状态与正文。HAR 两侧可独立选择调用记录。
- **结构化 JSON：** 路径、类型与缺失字段清晰对齐，区分缺失和 `null`，保留大整数精度、数组顺序和重复头／参数。JSON 缩进与对象键排列不会产生差异。
- **按需观察：** 请求／响应分区、搜索、仅差异和明确的忽略规则。被忽略项仍可查看，默认无忽略规则。
- **只读导入：** 不执行 cURL，不发送请求，不展开变量或读取命令引用的文件。常见凭据值默认遮罩，原文需显式显示；这不是完整脱敏或会话加密。
- **原生工作流：** 新建比较支持插件粘贴输入，记录选择与规则随本机会话恢复。保留摄影、文本、文件夹、图片、Hex、压缩包与 PDF 功能。

| 0.10.0 发行内容 | 包含能力 |
| --- | --- |
| Base | 文本、文件夹、图片、Hex 和内置压缩包插件 |
| Full | Base 全部能力，预装 PDF、Photography、API Compare |
| `CrossDiff-Plugin-API-0.1.0.crossdiffplugin` | 需要 0.10.0 宿主的独立 API 插件 |

每侧 API 输入最多 4 MiB UTF-8／500 次 HAR 调用；body 最多 1 MiB；JSON 最多 64 层／20,000 节点，每次调用最多 5,000 字段。无法取得正文时显示未知，超出结果显示预算时明确显示部分结果。XML 等非 JSON 正文按文本比较，cURL 支持常见导出语法子集；不包含 PCAP、实时抓包、接口请求执行、OpenAPI 契约或日志专用分析。[使用指南](../usage.md#api)

需要 macOS 14+，发行目标 Apple 芯片。仍为 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。Release 未发布前，相应目录下载 URL 不可用，请使用源码构建和本地插件包。

Draft release notes for the unpublished 0.10.0 source preview. The public download remains 0.8.0.

**🌟 Download guide: choose Base for everyday comparisons, or Full for PDF, Photography and API Compare out of the box. Once published, download `CrossDiff-0.10.0-base-macOS-arm64.zip` or `CrossDiff-0.10.0-full-macOS-arm64.zip`.**

API Compare reveals HTTP request and response changes locally, without accounts or uploads.

- Paste HTTP/cURL or import HAR; compare methods, addresses, repeated parameters and headers, status and bodies. Select HAR calls independently on each side.
- Compare JSON paths and types, missing versus null, exact numeric spelling/precision, and array order. Whitespace and object-key ordering do not create differences.
- Filter request/response sections, search fields, show only changes and apply explicit ignore rules. Ignored fields remain inspectable; no fields are ignored by default.
- No cURL execution, outgoing requests, variable expansion or referenced-file reads. Common credential values are masked for display; original sources need explicit reveal. Masking is not full sanitization or encrypted session storage.
- Full bundles API 0.1.0 alongside PDF and Photography. Base can install the separate `CrossDiff-Plugin-API-0.1.0.crossdiffplugin` with a matching 0.10.0 host. Earlier hosts lack the HTTP capability.

Input limits: 4 MiB UTF-8/500 HAR calls per side; 1 MiB per body; JSON depth 64/20,000 nodes; 5,000 fields per call. Missing bodies remain unknown and output-limit truncation is marked partial. Non-JSON bodies compare as text. cURL import supports a documented subset, not a shell. PCAP, live capture, API execution, OpenAPI contracts and specialized log analysis are not included. [Usage](../usage.md#api)

Requires macOS 14+; releases target Apple silicon. Ad-hoc signed, without Developer ID signing or notarization. Use source builds and local packages until publication makes catalog assets downloadable.
