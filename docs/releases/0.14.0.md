# CrossDiff 0.14.0

**🌟 下载指南：不想选版本？直接下载完整版 [CrossDiff-0.14.0-full-macOS-arm64.zip](https://github.com/JunyangZhangUSTC/CrossDiff/releases/download/v0.14.0/CrossDiff-0.14.0-full-macOS-arm64.zip)，已预装本版本全部官方插件，包括视频对比。**

这个版本把更清晰的文件夹浏览、更广的压缩包支持，以及图片、摄影、PDF 和视频增强带到同一个工作台。

- **文件夹，两边始终对得上：** 同一路径共用行、选择与滚动，缺失侧明确占位，目录联动展开。可切换目录树／列表，按名称、状态或大小排序，搜索和筛选当前范围；左右目录可独立更换。复制需等待完整比较与当前筛选完成，再预览并核验文件。
- **压缩包，直接看里面：** 新增无密码、单卷 7z（Copy／LZMA／LZMA2，含常见固实包）与受限 RAR，可与 ZIP、TAR 或本地目录互比，查看路径差异及跨路径相同内容，不解压到磁盘。RAR4 不支持固实，RAR5 仅支持算法 v0；密码、分卷及其他不支持的特性会明确拒绝，实际读取仍取决于系统库。[兼容范围](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.14.0/docs/usage.md#archives)
- **图片，找出共同内容：** 智能对齐帮助定位裁剪、缩放或旋转版本的共同部分；成功后可开启默认关闭的“相似区域”，用编号联动查看左右对应内容。虚线表示几何对应范围，填色表示核验后的近似相似区域；不保证像素完全一致，未标注也不表示不同。保留手动微调和恢复对齐前状态，不改源图。
- **摄影，把影调差异看具体：** 新增 RGB 单通道灰度预览、Lab L* 感知明度与 RGB 直方图，支持分开、叠加及占比差视图。悬停同步读数，拖选图表范围可在照片中定位像素；拍摄信息逐项对照。保留 HSL 分布、实际记录的处理曲线和命名区域，仅用于分析，不反推曝光或补猜缺失曲线。
- **PDF，更清楚地区分配对与推断：** 默认按页码比较，也可智能匹配或手动选择左右页面。证据不足时回退页码；按页码或回退模式下的单侧页使用中性标记，避免误称版本新增／删除。已确认的智能插删仍保留红绿标记；当前不包含 OCR。
- **视频，把不同版本放到一起看：** 新增双画面、双时间线与统一播放控制，支持手动时间偏移、逐帧浏览、左右声音或静音。暂停后滑动对照或查看帧差异，独立／联动框选局部，保存命名区域并循环片段。查看调整支持撤销／重做，不修改、转码或导出源视频。

所有比较继续在本机处理，沿用原生界面、浅深色与中英文设置。视频使用系统 AVFoundation 与 Core Image，无需额外下载大型模型或 FFmpeg。Full 预装全部官方插件；同版 Base 可通过插件页或本地包按需安装。

首版声明 MOV／MP4／M4V，实际支持以 macOS 解码能力为准，单侧时长上限 24 小时。逐帧要求可用的真实样本索引。差异图在暂停时工作，要求同像素尺寸与明确 Rec.709 SDR 标记；它是缩放帧的视觉预览，不是压缩质量评分。HDR 和色彩标记缺失的视频保留视觉浏览；自动剪辑片段匹配、视频导出与 HDR 数值分析后续研发。

只需要基础功能？选择 [Base 基础版](https://github.com/JunyangZhangUSTC/CrossDiff/releases/download/v0.14.0/CrossDiff-0.14.0-base-macOS-arm64.zip)，再按需安装插件。

适用于 macOS 14+ 的 Apple 芯片 Mac。当前使用 ad-hoc 签名，尚无 Developer ID 签名或公证。源码、插件包与校验文件随版本提供。

This release brings clearer folder browsing, broader archive support, and image, photography, PDF and video improvements into one workspace.

- **Folders stay aligned:** paired paths share rows, selection and scrolling, with clear missing-side placeholders and linked expansion. Switch between a tree and a flat list, sort by name, status or size, search and filter the current scope, or replace either folder independently. Copying requires a completed comparison and current filter, followed by a preview and file revalidation.
- **Look inside more archives:** compare unencrypted, single-volume 7z files (Copy/LZMA/LZMA2, including common solid archives) and a limited RAR subset against ZIP, TAR or local folders. Inspect path differences and identical content across paths without extracting to disk. RAR4 solid archives are unsupported; RAR5 is limited to algorithm v0. Passwords, multiple volumes and other unsupported features are rejected, and decoding remains subject to system-library capabilities. [Compatibility details](https://github.com/JunyangZhangUSTC/CrossDiff/blob/v0.14.0/docs/usage.md#archives)
- **Find shared image content:** smart alignment locates common content in cropped, scaled or rotated versions. After alignment, enable the optional Similar Regions overlay to inspect numbered correspondences on both sides. Dashed outlines show geometric correspondence; filled areas show verified approximate similarity, not pixel identity. Unmarked areas are not proof of differences. Manual refinement and restoration remain available without changing the originals.
- **Explore photographic tone:** view individual RGB channels in grayscale and compare Lab L* perceptual-lightness or RGB histograms separately, overlaid or as percentage differences. Linked hover readings and chart-range selections help locate pixels in the photographs; capture information is compared field by field. HSL distributions, recorded processing curves and saved named regions remain available. Analysis does not infer exposure settings or invent missing curves.
- **PDF pairing with clearer uncertainty:** compare by page number, use Smart Match or select each page manually. Insufficient evidence falls back to page order. Single-sided pages in page-order or fallback mode use neutral markers instead of implying revision additions or deletions; confirmed Smart Match insertions/deletions retain red/green markers. OCR is not included.
- **Review video versions together:** paired pictures and timelines with shared transport, manual offsets, frame stepping, A/B audio and mute. Pause for wipe or frame differences, make independent or linked local selections, save named regions and loop passages. Undo and redo viewing adjustments without editing, transcoding or exporting the source videos.

Comparison stays local, with native controls and existing light/dark themes and English/Chinese settings. Video uses system AVFoundation and Core Image, with no extra large-model or FFmpeg download. Full includes every official plugin; a matching Base host can install individual packages through the plugin page or from local files.

Initial containers are MOV, MP4 and M4V, subject to macOS codec support and a 24-hour limit per source. Frame stepping needs an available real sample index. Paused differences require equal pixel dimensions and explicit Rec.709 SDR tags; they are scaled-frame previews, not codec-quality scores. HDR and untagged footage remain available for visual browsing. Automatic edit correspondence, video export and HDR numerical analysis are future work.
