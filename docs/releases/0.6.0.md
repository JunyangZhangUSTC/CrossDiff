# CrossDiff 0.6.0

**内置二进制比较 · 原生 Hex 视图**

- “比较 → 二进制比较…”可将任意两个普通文件按字节比较，普通打开也能按内容识别二进制；多项输入保留明确配对。
- 对齐的双栏十六进制、ASCII 和独立源地址，红绿差异与空位区分修改、增加和删除。
- 提供逐处导航、左／右地址跳转、8／16 字节布局与选中复制十六进制，适配中英文、深浅色和窄窗口。
- 后台有界读取、虚拟化视口与取消；每侧上限 8 GiB，复杂区域明确提示粗略对齐。
- 原文件只读，会话仅保存文件路径。尚不支持二进制编辑、合并、补丁、远程二进制或三方 Hex。

保留文本、文件夹、图片和实验插件功能。需要 macOS 14+；本地验收使用 Apple silicon，Intel 与 macOS 14 实机尚未验证。应用仅 ad-hoc 签名，未做 Developer ID 签名与公证。

**Built-in binary comparison · Native Hex view**

- Compare any two regular files as bytes with Compare → Binary Comparison…. Ordinary Open also detects binary content; multiple files retain explicit pairing.
- Aligned hexadecimal and ASCII panes with independent source addresses, change highlights and insertion/deletion gaps.
- Change navigation, per-side address jumps, 8/16-byte layouts and selected hex copy, with bilingual light/dark and compact layouts.
- Bounded background reads, a virtual viewport and cancellation. Each input is limited to 8 GiB; complex regions show an approximate-alignment notice.
- Sources remain read-only; sessions store paths only. Binary editing, merging, patches, remote binary inputs and three-way Hex are not included.

Retains text, folder, image and experimental plugin workflows. Requires macOS 14+. Local checks use Apple silicon; Intel and physical macOS 14 are not verified. Ad-hoc signed, without Developer ID signing or notarization.
