# CrossDiff 0.7.0

**压缩包比较 · 基础版内置插件**

- “比较 → 压缩包比较…”将压缩包作为虚拟目录，与另一压缩包或本地文件夹比较；支持 ZIP、TAR 及 gzip、bzip2、xz 压缩的 TAR。
- 原生可展开目录树、路径筛选与仅差异视图，保留空目录和类型变化；“相同内容”分组查找两侧不同路径下的相同文件。
- 内容按大小与 SHA-256 校验；流式解码，不向磁盘解压，不覆盖来源。链接与特殊条目未验证，损坏、加密或超限包明确报错。
- 作为官方受限插件随基础版提供，使用统一管理、启停与运行机制；新增 `archiveCatalog` / `archiveTree` 实验接口与双语开发说明。

每侧最多 10,000 个条目、512 MiB 展开读取、单文件 256 MiB、压缩包 2 GiB。首版只读，不含 RAR、7z、ZIP64、密码、包内文件编辑、解压或写回。详见[用法与限制](../usage.md#archives)。

需要 macOS 14+，本地验收环境为 Apple silicon；Intel 与 macOS 14 实机尚未验证。仅 ad-hoc 签名，未做 Developer ID 签名与公证。

**Archive comparison · Bundled base plugin**

- Compare archives as virtual folders against another archive or a local folder. Supports ZIP, TAR, and gzip/bzip2/xz-compressed TAR.
- Native expandable trees, path filtering and Changes Only, with empty folders and type changes preserved. Same Content groups identify identical files across distinct paths.
- Size and SHA-256 verification, bounded streaming reads, no extraction to disk and no source writes. Links and special entries remain unverified; damaged, encrypted or over-limit archives fail explicitly.
- An official restricted plugin included with the base app, using the existing management and execution lifecycle. Adds the experimental `archiveCatalog` / `archiveTree` contract and bilingual documentation.

Per side: 10,000 entries, 512 MiB expanded reads, 256 MiB per file and 2 GiB archive input. Read-only; no RAR, 7z, ZIP64, passwords, in-archive editing, extraction or write-back. See [usage and limits](../usage.md#archives).

Requires macOS 14+. Local verification uses Apple silicon; Intel and physical macOS 14 are not verified. Ad-hoc signed, without Developer ID signing or notarization.
