# CrossDiff 0.5.0

**插件框架第一步 · PDF 文档比较**

- 保留原有 Mac 工具栏、标签页与文本、文件夹、图片体验。
- 新增原生插件窗口：本地选择／拖入、主动 HTTPS 下载检查、安装更新、启停、卸载和上一版本回退。
- 内置真实 PDF 插件，支持页码对应、插删页、原版面对照和可提取文字差异。扫描页提示人工查看，暂不含 OCR。
- 提供独立 JSON 算法示例及原生表格视图、中英文实验接口文档和可重复打包脚本。
- 受限 JavaScript 没有文件、网络或进程接口；高级原生插件需要显式完全信任和有效代码签名。完全信任不属于安全沙箱；此预览拒绝带系统隔离标记的原生插件。

这是实验性框架预览，尚无稳定 SDK 承诺。当前界面与附带插件仍为两方比较；文本三方合并、远程目录、Hex、其他专业插件和发行组合继续按路线图推进。

PDF 每侧上限 48 MiB，最多分析前 200 页，文字与 384 px 页面指纹有预算限制；预览匹配不等于完整 PDF 精确相同。需要 macOS 14+；本地验收使用 Apple silicon，Intel 和 macOS 14 实机尚未验证。应用仅 ad-hoc 签名，未做 Developer ID 签名与公证。

**First plugin framework preview · PDF comparison**

- Retains the native toolbar, tabs, and existing text, folder and image workflows.
- Adds plugin management: local/drop installation, explicit HTTPS download inspection, updates, enable/disable, uninstall and previous-version rollback.
- Bundles a real PDF algorithm with page correspondence, inserted/deleted pages, native layout previews and extracted-text differences. Scanned pages require visual review; OCR is not included.
- Includes an independent JSON algorithm example, native table renderer, bilingual experimental API docs and reproducible packaging tools.
- Restricted JavaScript has no file, network or process APIs. Native plugins need explicit full trust and a valid code signature. Full trust is not a sandbox; this preview refuses quarantined native executables.

The SDK is experimental. The current UI and supplied plugins remain two-way; text three-way merging, remote folders, Hex, other professional plugins and edition bundles remain planned.

PDF inputs are limited to 48 MiB each and the first 200 pages, with bounded text and 384 px page fingerprints. Preview matching does not imply exact full-document equality. Requires macOS 14+; local verification uses Apple silicon. Intel and physical macOS 14 have not been verified. Ad-hoc signed only, without Developer ID signing or notarization.
