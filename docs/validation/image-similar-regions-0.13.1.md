# 0.13.1 图片相似区域验收

环境：2026-10-04，macOS 26.6.2、arm64；工作目录为 `CrossDiff-image`，分支为 `zhangjy/image`。所有依赖、构建、测试数据、日志与截图均留在此子项目内。平台下限仍为 macOS 14，本次未在最低系统版本或 Intel 上运行。

## 实现范围

- 智能对齐成功后提供默认关闭的“相似区域 / Similar Regions”按钮。首次开启时后台核验，保持显示直到用户关闭；完成的结果可复用。
- 使用现有 OpenCV 对固定配准后的局部纹理与 RGB 残差进行检查，保留最多 12 个较大的连通区域。区域具有半透明填色、轮廓与左右对应编号，可点击编号或前后箭头联动强调。
- 保留遮挡和局部修改形成的空洞，不以特征点外包矩形代替相似内容。当前手动缩放、旋转、翻转与位移仅影响证据的显示位置；分析不覆盖手动参数，不修改源文件或像素差异结果。
- 取消、换图、重新读取、重新智能对齐及恢复对齐前状态均阻止过时分析结果回写。切换标签保留当前结果，关闭后重新开启可使用同一输入的缓存。
- 中英文、浅深色、并排／叠加／滑动／像素差异布局沿用现有图片工作区。详细算法边界见[设计说明](../architecture/image-similarity-regions.md)。

验收发现并修复两项问题：

1. 新信息栏的 accessibility identifier 被子按钮继承，导致原生检查不能准确访问上一处／下一处。将信息栏设为包含独立子元素后，编号与导航按钮可分别访问。
2. 新增固定信息行使英文窄窗口由 580 像素撑高至 612 像素。将信息行放入可伸缩画布内部并保留画布空间后，中英文浅深色均保持 860 × 580。失败检查未计为通过；修改后完成定向和完整回归。

## 证据边界

- 输出基于最长边 1600 的 8-bit sRGB 分析预览，是局部纹理近似证据，不是原图像素相等证明或语义分割。
- 阈值是保守启发式，不是校准过的相似概率。平坦背景可能不标记；轻微色差、亮度变化或缩略预览丢失的小细节可能仍在已标区域中。未标注不能据此判断删除或不同。
- 只核验现有全局配准，不新增独立局部变换搜索。多处独立拼接、透视和不同拍摄视角仍可能无法覆盖。
- 本次生成样例与少量上游实景验证不代表大规模图片语料准确率。VoiceOver 完整人工操作、真实用户图片及最低系统版本仍需后续验收。

日志在被忽略的 `.build/similarity-*.log`，完整父窗口截图在 `.build-image-workflow-checks/renders/image-similarity-*.png`。这些诊断文件不提交或用作公开宣传素材。应用为 `dist/CrossDiff.app`，使用本地 ad-hoc 签名；通过 `bash scripts/open-dev-app.command` 使用本项目开发数据启动。本记录描述本地验收，未发布 Release。
