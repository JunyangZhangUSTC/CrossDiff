# 0.4.1 图片对齐验收

日期：2026-10-01。环境：Apple silicon、macOS 26.6.2、Swift 6.3.3。产物：`dist/CrossDiff.app`，版本 `0.4.1`，构建号 `11`。

- `bash scripts/tests/check-image-comparison.sh`：40 项断言通过，覆盖顺时针旋转、独立缩放、裁剪位移、重叠区域、透明边界、EXIF、首帧、画布限制与取消。相同检查在优化编译下也通过。
- `bash scripts/tests/check-image-workflow.sh`：真实原生窗口检查通过。左右滑块和数值框独立生效，聚焦输入框后滑动或重置不会在失焦时恢复旧值；模式、标签切换保留状态，过时任务不能覆盖最终结果。裁剪图对齐后重叠差异为零，源文件逐字节保持不变。
- 在检查进程内部派发原生鼠标事件，验证图片拖动位移与预览坐标相符；分界手柄从 50% 移至 60% 时不平移图片。持续输入期间的中间渲染通过模型交互模拟检查，不等同于人工连续拖动验收。
- 已查看七张完整父窗口截图，覆盖中文／英文、浅色／深色及 1220／860 点宽度；控件、数值、图片和提示均可见。截图和最终结果位于 `.build-image-workflow-checks/renders/`，不提交生成物。
- `bash scripts/tests/check-workflow.sh`：现有完整窗口回归通过，包括合并、独立撤销、查找替换、预览复制、保存恢复、快捷键、设置和文本／目录／图片双语切换。
- Release 构建、`codesign --verify --deep --strict dist/CrossDiff.app`、发布敏感信息规则扫描及 `git diff --check` 通过。

首次原生检查因沙箱无法连接应用服务而未执行；在允许访问 AppKit 的环境中重跑后通过。测试驱动已处理原生控件标识位于 NSCell 的情况，并等待测试窗口激活后派发鼠标事件。

所有测试数据、会话、缓存和产物均在项目内。未验证 Intel、最低系统版本的实际运行、VoiceOver、真实输入法候选窗口或长期使用。未运行远端 CI，也未发布新版本。当前功能使用手动对齐及最长边 1600 像素预览，缩放、旋转与压缩可能引入重采样差异。
