# 0.13.0 图片智能对齐验收

环境：2026-10-04，macOS 26.6.2、arm64。本次只在项目目录内研发和验证；应用平台下限仍为 macOS 14，此次未在该最低版本及 Intel 上运行。

## 实现范围

- Base／Full 的基础图片比较内置“智能对齐”，完全本地，不需要模型或 Python 运行时。
- OpenCV 4.12.0 SIFT（每侧最多 4000 特征）、双向 Lowe 比率匹配、RANSAC 相似变换；支持具有充分共享细节的旋转、等比缩放、平移、裁剪和部分局部修改。
- 透明区域按 alpha 及特征尺度过滤；使用内点数量、比例、重投影残差、空间分布和竞争变换检查证据。前景透明轮廓、重复图案、低纹理和不可靠对应不能无条件应用。
- Swift 将右图到左图的源坐标变换转换为原生控件的中心缩放／旋转／位移。变换超出控件范围时拒绝，不静默截断。
- 成功后可查看编号对应点、继续微调或恢复操作前状态；失败与取消不改手动参数。单个标签的重试串行执行，换图、重新读取和手动修改阻止旧估计覆盖新状态。
- 对应点是证据采样，不是分割边界；残差不是正确率；未匹配不等于删除或遮挡。多个局部拼接、透视、自动翻转、非等比变换与学习型模型不在此版范围。

## 性能与实际含义

- C++ 生成样例批次计算约 0.7 秒，不含构建。
- 已校验 OpenCV 源码自带的 `graf1.png` 实景：裁剪匹配约 0.06–0.07 秒；22° 旋转、0.83 倍缩放版本约 0.09–0.10 秒。独立控制点误差小于 1 个分析像素。
- 以上是少量确定性样例的本机记录，不是准确率基准或所有图片的速度承诺。大规模真实照片、强透视、极小裁剪和不同拍摄视角仍需要后续语料评估。
- 分析和差异显示仍基于最长边 1600 的 8-bit sRGB 预览；重采样会产生细微差异，不提供全分辨率无损相等证明。
- 最终本地可执行文件为 18,048,448 字节，相比改动前的开发包增加约 3.5 MB；这是可执行文件增量，不是压缩发行包增量，尚未打包公开 Release。
