# 0.13.1 摄影分析增强验收

环境：2026-10-04，macOS 26.6.2、arm64。开发、依赖、测试数据和构建产物均位于摄影子项目，分支为 `zhangjy/photo`。应用下限仍为 macOS 14；本轮未在最低系统版本或 Intel 上运行。

## 本轮范围

- 两侧同步切换原图与 R/G/B 通道灰度预览，照片显示和统计通道独立。
- Lab L*、RGB 总览与单通道直方图；默认分开显示，手动点击“叠加”按钮可切换为叠加，也可查看 B−A 分布差。双方按各自有效像素数归一化，共用同一通道的坐标尺度。
- 分箱范围高亮仅作用于当前 ROI 内的预览，以 32% 琥珀色混合保留图像细节；不反馈改变选区和统计，也不改写源文件。
- Lab 明度中位值、P90−P10 跨度、低／高明度占比；EXIF 逐项对照与明确缺失值。原 HSL、真实 XMP 曲线与保存区域保留。
- 新显示偏好随会话恢复；缺少显示偏好的旧状态采用原图、Lab L* 与分开默认值，已保存的布局按原选择恢复。临时范围高亮不持久化。

## 验证中修正的细节

- 图表绘制、点击和刷选统一为实际 `i/256` 分箱边界，最终箱包含端点；差值图例明确正负方向和百分点。
- 高亮从不透明纯色改为库提供的混合显示，放大预览只接受完成的通道图；拍摄曝光补偿不再显示冗长浮点尾数。
- 明度摘要移至图表上方，主题变化同步更新原生菜单；中英文读数保留单位和统计定义。
- 原生菜单通过实际菜单项动作验收；可选文本的 AX 读取同时检查子节点和富文本。首次辅助函数无法触发菜单和提取这些值，修正后重跑通过，未改模型来绕过交互。
- 连续悬停依赖实际指针相对于窗口的位置。测试副本使用公开窗口位置约束覆盖，将图表短暂移到静止指针下，触发真实移动事件后恢复；正式窗口不变、指针不移动。前几次因窗口被系统移回屏幕内或指针在等待期间移动而失败，未计为通过。移除事件前等待、恢复后等待布局后，最终悬停和拖选均通过。运行此项时应短暂停止移动鼠标。
- 沙箱内 Core Image 系统服务受限时发生的解码失败不计为通过；实际引擎与原生窗口检查在允许系统服务的环境下执行，仍使用项目内隔离数据。

## 边界与未验证范围

Lab L* 是感知明度，不能当作物理亮度、拍摄 EV、相机动态范围或 RAW 传感器剪切。预览最长边 2048、ROI 统计最长边 4096，两种采样可能在细小纹理或边缘处产生覆盖差异。低／高明度阈值约为 L* 20/80，属于描述性分组，不自动诊断欠曝或过曝。

本轮没有新增真实 RAW 机型覆盖、HDR 专业分析、波形、RGB Parade 或矢量示波器，也没有宣称这些能力已完成。原 Apple RAW 解码路径保持，支持仍取决于系统、机型与编码模式。

产物为当前子项目的 `dist/CrossDiff.app`，本地 ad-hoc 签名。使用 `scripts/open-dev-app.command` 启动可保持运行数据在本项目内。本轮未推送、合并或发布 Release。
