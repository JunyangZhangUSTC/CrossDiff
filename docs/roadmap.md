# 研发路线：对比一切

2026-10-02 更新。已完成能力以 [README](../README.md) 与 [CHANGELOG](../CHANGELOG.md) 为准；以下区分已完成的版本切片与后续研发顺序；未标为已交付的目标不是现有功能，也不承诺发布日期。

产品范围见 [产品方向](product-vision.md)，技术提案见 [框架设计](architecture/compare-everything.md)，接口目标见 [插件开发规范](plugins/development.md)。

## 第一阶段：框架与真实插件闭环

**0.5.0 首个可运行切片：** 已接通官方 PDF 和独立 JSON 示例算法、插件管理、选择／拖入／HTTPS 下载检查、启停／卸载／版本回退及两种原生结果视图。受限运行时选用无宿主 I/O 桥接的 JavaScriptCore 独立进程，明确不声称操作系统沙箱。三方／多对象仅有协议角色校验；基础功能统一来源迁移与任意领域视图尚待推进。

- 在保留现有文本、文件夹、图片体验的前提下，引入能力注册、版本化来源和会话描述、领域结果及任务生命周期。
- 用现有文本与图片适配器，以及官方 PDF 插件验证抽象；PDF 先做页面对照与可提取文字的差异，不以文字提取失败冒充相同。
- 首版支持第三方本地插件安装，默认受限，保留用户显式启用的完全信任模式。独立示例必须实际实现比较算法，不能只是配置宿主内置功能。
- 打通应用内下载、Release 包本地选择和拖入安装；统一兼容检查、信任说明、启停、卸载、更新与回退。
- 先验证受限运行时与高级原生执行，以及专业视图交付路线。ExtensionKit 在 macOS 14 的发现、签名和独立安装仍是原型问题，不提前宣称稳定支持。
- 基础版与专业版使用同版本宿主和兼容插件；基础版安装同样插件能获得相同视图及算法能力。

**通过门槛：** PDF 和真实第三方插件从安装到结果显示可用；受限权限可以被实测强制；完全信任模式标识准确；崩溃／取消／更新不破坏宿主状态；旧会话与原生编辑不回退。公开契约即验证两方、三方与多对象输入角色，不在发布 SDK 后才发现只能表示左右两侧。

**0.7.0 新增基础版内置压缩包插件：** 复用既有受限执行与管理机制，交付虚拟目录、目录树视图、路径差异和同内容分组；压缩包与本地目录可交叉比较。基础能力可由内置插件提供，现有其他宿主比较功能的统一适配按需要渐进进行。

## 第二阶段：文本三方合并与多对象工作台

- 有共同原始版本的文本三方合并：base、两份修改版本、独立结果、冲突定位、解决状态与手动保存。
- 无共同原始版本的多对象比较：基准对照、按需选择配对、摘要和专业布局；不默认计算所有两两组合。
- 比较器声明输入上限和实际支持的模式，未支持的方式明确提示。
- 验证空 base、同位置插入、修改与删除冲突、不同换行、Unicode、撤销与保存；窄窗口不强塞多个无法阅读的列。

## 第三阶段：补齐基础版来源与二进制能力

**0.6.0 已提前交付本地 Hex：** 内置只读双栏、原始偏移、插删对齐、差异导航、地址跳转和有界视口。远程来源、二进制编辑、补丁与三方比较仍未实现。

- 建立有界字节读取、分段结果和原始偏移映射，先完成本地 Hex 的插入／删除对齐与虚拟化视图。
- 小范围精确算法与大文件锚点／局部精化分别提供预算和精度说明；差量补丁导出作为独立能力评估。
- 用本地与 SSH / SFTP 两种实际来源验证互比，再加入 WebDAV、SMB、FTP／FTPS 的兼容实现。
- 远程第一阶段只读，结果可另存本地；连接失败、部分扫描、来源变动与弱快照明确显示。远程写回另立里程碑。
- txt、Markdown、HTML、JSON、XML、YAML 等保持原文比较，逐步增加可选择的结构解释与预览，不静默改写原始格式。

**通过门槛：** 来源交叉组合、非 ASCII 路径、大文件、取消、断线、扫描中修改、权限失败和缓存配额都有验收；不将时间戳相同或读取失败显示为内容相同。性能上限由样例与机器实测决定。

## 第四阶段：官方专业插件与发行组合

**0.8.0 已交付基础版／完整版打包与独立插件分发：** 官方目录随应用提供，按用户点击从 GitHub Release 下载、校验并安装；0.8.0 完整版包含压缩包和 PDF 两个官方插件，专业版本随相应插件陆续扩展。

**始于 0.9.0 源码预览的 Photography 0.1.0：** 只读双图、默认 RGB／HSL 明度直方图和差异说明，展开 HSL／真实记录曲线／拍摄信息；左右独立或联动选区、最多 32 组命名配对随会话保存。Apple 负责 RAW／颜色管理，OpenCV 4.12.0 负责现成统计。当前 0.11.0 源码 Full 预装摄影，Base 可安装同版本独立包。[实现设计与边界](architecture/photography-comparison.md)

**始于 0.10.0 源码预览的 API Compare 0.1.0：** HTTP／cURL／HAR 导入，结构化请求与响应、JSON 路径与类型、显式忽略规则、只读本地解析；Full 预装，Base 可安装独立包。[设计与边界](architecture/api-comparison.md)

**0.11.0 源码已实现 Audio 0.1.0：** 声道波形、STFT 时频图与平均频谱、可保存的命名区域、独立速度／音高试听；固定版本 Olaf 引擎返回同源录音中固定速度的截取、重排和重复片段候选。分析最多 8 声道，试听限单声道／立体声；未匹配不代表删除，边界不承诺精确到采样。Full 预装，同版本 Base 可安装独立包。[设计与边界](architecture/audio-comparison.md)

上述源码能力的公开下载状态以 [README](../README.md) 为准；构建通过、生成草稿与公开发布分别确认。

按照真实使用优先级逐个交付，不以安装全部重量级依赖作为基础应用启动条件：

- 文档：扩展 PDF，再做 Word、Excel 与 PowerPoint；分别验证文字、版面、公式与值。扫描件、OCR 和复杂论文版式有独立样例集。
- 摄影后续：扩大真实 RAW 机型／编码样片验证，评估 HDR、波形、矢量示波图、图表反向高亮与细节观察。新增专业指标先确认 Apple 或成熟专业库的现成实现和语义；快门等显示文件记录，不从成片反推确定参数或调色曲线，继续保持只读。
- 开发与运维后续：扩展 API 格式和协议，评估网络包重组、数据库结构与快照。普通日志复用文本比较；实时抓包、OpenAPI 契约和接口请求执行尚未实现。
- 音频后续：扩展真实音乐／语音样例，研究独立变速、变调和连续速度变化下的自动对应、精细边界与复杂混音；完善长音频性能、设备试听和专业指标。手动试听参数不能当作自动估计结果。
- 视频：另行设计帧与音画时间线、对应映射和同步预览；音频插件不等于已支持视频。
- 模型：ONNX、PyTorch／安全张量格式，结构和权重分离、惰性切片、数据类型／形状与误差分析，不为对比默认执行模型代码。
- 基础版、完整版与独立插件包已按固定清单生成；摄影师版、媒体工作者版和开发者版待对应能力与组合验证后再提供。

## 全程并行的体验与可靠性

- 保留上下文折叠、语法颜色、字号偏好、文件夹多选操作、Finder 拖放、键盘与 VoiceOver 的打磨计划。
- 将手动保存移出主线程，并保留文件编码、外部修改检测、当前 revision 和失败反馈。
- 深浅色、中英文、最小窗口、焦点、撤销、输入法、搜索、复制和实际父窗口渲染持续回归。
- 比较结果记录覆盖范围、规则和精度，未比较、部分失败和不支持不能显示为相同。
- 每个可用阶段保留明确验证记录。仅在远程 CI 实际运行后才声称 CI 通过；当前资料研究不替代运行时或签名实验。
- 发布 SDK 前落实示例、兼容测试、依赖许可证与源码提供方式；正式公开下载体验需验证 Developer ID 签名和公证路径。
- 所有研发写入、测试数据、缓存和产物继续限定当前项目。
