# 研发优先级

以临时文字、代码文件和代码目录的可靠日常使用为基础，再扩展论文 PDF。已完成能力以 README 与 CHANGELOG 为准。

## 下一轮：阅读与文件操作

- 只显示变化与上下文折叠：保留原始行号，展开位置不跳动，跳转可自动展开目标。
- 文件夹比较中的单侧文件查看、状态筛选和多选复制；继续使用“预览后执行”，不引入隐式删除。
- 字号与外观偏好、键盘操作、VoiceOver 验收，补充 Finder 拖放和系统文件面板的人工回归记录。
- 将手动文件保存移出主线程，同时保留外部修改校验、文件编码、当前 revision 和保存失败反馈。

## 后续：论文 PDF

- 先完成双侧页面、缩放、同步翻页与可选择文字的差异定位。
- 区分“可提取文字”和扫描页；提取失败须明确提示，不能把空结果显示为相同。
- 对双栏、页眉页脚、连字符换行、公式和参考文献建立真实论文样例集。
- OCR、版面与图片差异按独立能力评估；PDF 提取结果不直接冒充视觉等价。

## 更后续

代码语法颜色、统一视图、报告导出、结构化表格、Word、三方合并，以及公开发行所需的 Developer ID 签名和公证。

## 持续验收

- 正确性：UTF-16、组合字符、CRLF、末尾换行、单侧空文件、忽略选项、撤销、复制与保存。
- 体验：完整原生窗口的浅深色与窄宽布局；文字与高亮实际可见，行号栏不遮正文。
- 性能：大文件的首次比较、连续输入、旧任务取消、匹配数量、窗口缩放、后台写入和退出等待。测量须说明机器与样例，不将一次运行当作延迟承诺。
- 版本：每个可运行里程碑提交到本地 Git；CI 配置须在远程实际执行后才能声称通过。研发数据和产物全部留在本项目内。
